# 5. ユーザーマニュアル (User Manual)

## 5.1 はじめに
Monaは、製品の不具合データとセンサーデータを統合し、可視化・分析するためのツールです。

### ログイン方法
1.  管理者が発行したユーザーIDとパスワードを入力します。
2.  「ログイン」ボタンをクリックします。

## 5.2 機能別ガイド

### 不具合傾向を確認する (Defect Trend)
製品全体の不具合発生状況を俯瞰します。
1.  メニュから「不具合傾向」をクリック。
2.  **機種シリーズ**や**期間**を選択して「更新」ボタンをクリック。
3.  **上段グラフ:** いつ不具合が多かったかを確認。
4.  **中段グラフ:** どの製造月に不具合が偏っているかを確認。

### パトロール結果を確認する (Patrol List)
システムが自動検知した異常を確認します。
1.  メニューから「パトロール結果」をクリック。
2.  **ランクA**（重要）などで絞り込み、「検索」をクリック。
3.  異常検知された機番の一覧が表示されます。

### 不具合要因を解析する (Factor Analysis)
「なぜ不具合が起きたのか？（どの値がおかしいのか？）」をAIが自動分析します。

1.  メニューから「要因解析」をクリック。
2.  解析用データ（CSV等）をドラッグ＆ドロップでアップロードします。
3.  解析が完了すると、不具合と関連が強い項目のランキングが表示されます。
4.  **見方:**
    *   **順位:** 影響度が大きい順。
    *   **方向性アイコン:**
        *   ⬆️ NG: 値が「高い」と不具合になりやすい。
        *   ⬇️ NG: 値が「低い」と不具合になりやすい。
5.  リストをクリックすると、右側に詳細グラフ（正常品との比較）が表示されます。

## 5.3 トラブルシューティング
*   **解析エラー:** 「NaN」や「Inf」などの不正なが含まれていないか確認してください。
*   **ログインできない:** 管理者にパスワードリセットを依頼してください。
