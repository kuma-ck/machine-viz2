# 4. テスト仕様書 (Test Specification)

## 4.1 テスト方針
*   **単体テスト:** 主要なユーティリティ関数（解析ロジック等）に対して実施。
*   **結合テスト:** APIエンドポイントのレスポンス確認。
*   **システムテスト:** UIを通したエンドツーエンドのシナリオ確認（手動実施）。

## 4.2 テストシナリオ (System Test)

### 4.2.1 認証
| ID | 項目 | 手順 | 期待値 |
|---|---|---|---|
| AUTH-001 | ログイン成功 | 正しいユーザー/PWでログイン | トップ画面へ遷移すること |
| AUTH-002 | ログイン失敗 | 間違ったPWを入力 | エラーメッセージが表示されること |
| AUTH-003 | 未認証アクセス | 未ログイン状態で `/` へアクセス | `/login` へリダイレクトされること |

### 4.2.2 不具合傾向表示 (Defect Trend)
| ID | 項目 | 手順 | 期待値 |
|---|---|---|---|
| TRD-001 | 検索実行 | 期間・シリーズを指定して検索 | チャートとリストが表示されること |
| TRD-002 | 詳細確認 | チャート上のバーをクリック | 該当日のデータに絞り込まれること（※要実装確認） |

### 4.2.3 パトロール結果 (Patrol List)
| ID | 項目 | 手順 | 期待値 |
|---|---|---|---|
| PTL-001 | フィルタリング | ランクAを指定して検索 | ランクAのデータのみ表示されること |
| PTL-002 | 画面遷移 | 行の「要因解析」ボタン等は未実装（※要件により削除有無確認） | - |

### 4.2.4 要因解析 (Factor Analysis)
| ID | 項目 | 手順 | 期待値 |
|---|---|---|---|
| ANA-001 | ファイルアップロード | CSVファイルをD&D | 解析が開始されること |
| ANA-002 | 結果表示 | 解析完了を待機 | 重要度ランキングが表示されること |
| ANA-003 | グラフガイド | リストのアイテムをクリック | 右側に詳細グラフ（箱ひげ等）が表示されること |
| ANA-004 | エラー系 | 不正なファイル（txt等）をアップロード | エラーメッセージが表示されること |
| ANA-005 | 大規模データ | 1000件以上のデータをアップロード | AI解析モード（LightGBM）で動作すること（要Libomp） |

## 4.3 テストデータ
*   `scripts/seed_data.py`: DB機能確認用のダミーデータを生成。
*   `generate_large_dataset.py`: 解析機能確認用のCSVデータを生成。
